# Hasset Pastry digital menu

A mobile-first Next.js frontend for the Hasset Pastry QR menu. It includes a bilingual English/Amharic customer menu, search, categories, product detail and cake-size selection, a local cart / waiter handoff simulation, theme toggle, feedback board, and mock admin dashboard.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

All mock products are centralized in `src/data/menu.ts`, ready to be replaced by a future API.
